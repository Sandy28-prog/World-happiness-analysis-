# World Happiness Report Analysis(2005-2021)
## Project Overview
This Project explores global happiness Trends using data from the World Happiness Report (2005-2021).
The objective was to analyze which economic and social factors most strongly influence national happiness levels.
## Key Features
-Data cleaning and preprocessing
-Dataset merging (2005-2021)
-Region classification intergration
-Correlation heatmap Analysis
-Global happiness visualization
-Time-Series Analysis by Region
## Tools Used 
-Phython
-Pandas 
-Seaborn 
-Plotly
-Google Colab
## Key Insights
-Strong correlation between GDP per capita and happiness
-Social Support and life expectancy significantly impact happiness
-Negative perception of corruption lowers happiness
-Clear regional happiness divide (Europe/North America vs Sub-Saharan Africa)
